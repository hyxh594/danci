# 浮词 · CET-6 背词器（第一版）

这是一个本地桌面背词器：悬浮卡片式界面、内置完整六级词库（按真题词频排序）、记住/没记住持久化、间隔复习、导入导出和自定义单词。

## 启动

需要安装 Node.js 18+ 和 Electron 运行时。

```powershell
npm run desktop
```

桌面版快捷键：`Ctrl + Shift + Space` 显示或隐藏悬浮窗；关闭窗口会缩到托盘，退出请使用托盘菜单。程序只保留桌面入口，Electron 缺失时不会再自动打开浏览器版。
学习状态唯一保存在项目目录的 `fuci-cet6-state.json`，浏览器版不会再参与运行，也不会读取浏览器 LocalStorage。每次保存还会同步更新 `fuci-cet6-backup-latest.json`；这两个文件都已加入 Git 忽略规则。词库页面可用“恢复备份”选择完整备份 JSON，在确认后恢复词库、学习进度、复习历史和设置；“导入词库”仍用于追加普通 JSON/CSV/TXT 词条。

桌面悬浮窗默认进入超级悬浮模式：它是独立的 320×190 迷你卡片，打开即为紧凑最佳尺寸，CET6、进度、单词、释义按钮和记忆按钮都位于同一张卡片内。超级模式只保留右上角的模式切换和隐藏到托盘按钮，透明度统一在设置页调整。需要完整功能时可点击 `⤢` 切回普通模式（360×560）。拖动卡片空白区域可以移动窗口，八个边缘和角落都可以拉伸；拉伸后的尺寸会自动记住；点击 `×` 会真正隐藏窗口，之后可从托盘恢复。
超级模式卡片两侧提供左右箭头，可在当天队列中切换单词而不改变学习结果；普通模式首页和词库页的统计数字均可点击查看对应词条详情。

## 已实现

- 默认内置 1253 个 CET-6 六级标记词，按真题词频排序；
- 点击“显示释义”，再点击“记住”或“没记住”；
- 结果即时保存到桌面端 LocalStorage，刷新或重新打开后仍保留；每日新词批次按日期保存，同一天完成后重启不会重新发放新词；数量按今日首次学习数控制，调高只补差额，达到新上限后停止发放，调低不回收已分配词并在次日按新上限计算；
- 简单间隔重复：记住后 1、3、7、14 天递进，忘记后 10 分钟复习；
- 复习/词库/设置三个页面；
- 普通模式首页提供学习概览：总词数、未学习词数、今日新学、今日复习和按每日计划估算的首轮完成日期；
- JSON、CSV、TXT 导入；JSON 备份导出；
- 快捷键：Space 显示释义，1 没记住，2 记住；
- 可添加自定义单词和设置每日新词数量；首批高频词附带更完整的常用多义释义。

## 数据说明

默认词库由 `exam-data/CETVocabulary` 的 `cet_full_list.json` 生成：筛选其中标记为六级（★）的词条，并按真题词频降序排列。该仓库声明数据采用 CC BY-NC-SA 4.0，程序代码采用 MIT；发布时请保留数据来源和许可证。词库页面也保留了导入入口，方便替换为你有权使用的完整 CET-6 JSON/CSV 词库。

重新生成默认词库（需要项目内的 `.cache-cet` 源数据）：

```powershell
npm run build:wordbank
```
